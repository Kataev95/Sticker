# Sticker — Telegram GIF → WEBM video sticker bot

Конвертирует GIF/MP4/WEBM/MOV в прозрачные WEBM VP9 видеостикеры и создаёт наборы Telegram.

## Ubuntu VPS

1. Установите Docker Engine + Compose plugin.
2. `cp .env.example .env` и впишите `BOT_TOKEN` от @BotFather.
3. `docker compose up -d --build`
4. Логи: `docker compose logs -f --tail=100`

Отправьте GIF как документ или анимацию. Бот пришлёт WEBM и кнопки создания/добавления стикерпака. Стикерпаки создаются от имени пользователя через Telegram Bot API.

### Настройки

- `REMOVE_BG=true` — удаление фона rembg (нейросеть u2netp).
- `BG_MODEL=u2netp` — модель; `u2net` качественнее, но тяжелее.
- `ALLOWED_USER_IDS=12345,67890` — разрешённые Telegram ID; пусто = доступ всем.
- `MAX_INPUT_MB=18` — лимит загрузки.

### Ограничения

WEBM VP9, 512×512, не более 3 секунд, 30 FPS и 256 KiB, без звука. Бот пробует разные степени сжатия, но сложная анимация может не уложиться. Зацикливание коротких роликов не гарантирует бесшовного перехода. Удаление фона на каждом кадре может мерцать и ошибаться на волосах. Первый запуск скачивает модель. Рекомендуется VPS 3+ ГБ RAM. Проверяйте прозрачность на реальном клиенте Telegram. Состояние диалога хранится в памяти и сбрасывается при рестарте. Не публикуйте `.env`.
